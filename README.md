# Windows Server 2022 Active Directory Home Lab

**January 2025 – Present**

A hands-on home lab project focused on learning and practicing **Windows Server administration, Active Directory, and identity and access management** in a virtualized environment.

### Key Activities

* Installed and configured **Windows Server 2022** in a virtual machine environment.
* Installed and configured **Active Directory Domain Services (AD DS)** and established a Windows domain environment.
* Created and managed **Active Directory users, security groups, and Organizational Units (OUs)**.
* Configured and applied **Group Policy Objects (GPOs)** to manage user and computer settings.
* Configured **file sharing and access permissions** within the domain environment.
* Practiced **user account administration**, including creating, disabling, unlocking, and resetting user passwords.
* Configured and tested **DNS** services required for Active Directory functionality.
* Joined Windows client machines to the Active Directory domain and tested domain authentication.
* Troubleshot common **network, DNS, and domain connectivity issues** within the lab environment.

### Skills Practiced

**Windows Server 2022 | Active Directory | AD DS | DNS | Group Policy | User & Group Management | Organizational Units | File Sharing & Permissions | Domain Administration | Network Troubleshooting | Virtualization**
